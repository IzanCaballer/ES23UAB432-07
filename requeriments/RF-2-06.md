# Requirement

### ID: 
RF-2-06
### Type/Category:
Funcional
### Version:
1.0
### Title:
Disponibilitat cuiners
### Description: 
Els cuiners poden sortir com "No disponible". S'indicarà l'hora de pròxima disponibilitat i els clients podrán reservar una comanda per a quan estigui disponible
### Relations:
Sense relacions
### Comments:  
S'haurà de poder catalogar com "No disponible" als cuiners i assignar-li una hora de retorn de disponibilitat. 
Encara que no estiguin disponibles, els usuaris podran fer comandes assignant-li una hora que el cuiner estarà disponible.
